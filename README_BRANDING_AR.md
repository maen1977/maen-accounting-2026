# تخصيص الاسم والأيقونة

- اسم التطبيق بعد التثبيت على أندرويد: `Maen Accountings`
- الأيقونة مخصصة لبرنامج محاسبة، وتم وضع ملفها في:
  `assets/icon/maen_accountings_icon.png`
- عند البناء عبر GitHub Actions يتم توليد الأيقونات تلقائيًا.
- عند البناء محليًا:

```bash
flutter pub get
dart run flutter_launcher_icons
flutter build apk --release
```

## توضيح المشتريات والمصارف داخل الواجهة
- **المبيعات اليومية**: إجمالي ما تم بيعه في اليوم.
- **المشتريات / تكلفة البضاعة**: تكلفة الأصناف التي تم بيعها.
- **المصاريف التشغيلية**: مثل النقل والإيجار والعمالة والمصاريف الإدارية واليومية.
- **صافي الربح** = المبيعات - المشتريات - المصاريف التشغيلية.

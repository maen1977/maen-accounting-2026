# Maen Accounting v2.6.0 — Advanced Reporting Release

تقرير سنوي شهري مع المقارنة مع السنة السابقة، تقرير توزيع المصروفات حسب الفئات الملونة، اتجاه الادخار الشهري مع مقارنة أهداف الخطة المالية، تفاصيل المستحقات المتأخرة في المركز المالي للشركات، وتصدير التقارير الشخصية إلى CSV.

## الميزات الجديدة

### التقارير المتقدمة (صفحة التقارير)
- **التقرير السنوي**: جدول شهري كامل للدخل والمصروفات وصافي الربح، مع أفضل وأسوأ شهر، ونسبة التغير عن السنة السابقة لكل شهر.
- **توزيع الفئات**: ترتيب المصروفات حسب الفئات بنسب مئوية وأشرطة تقدم ملونة حسب حجم الإنفاق.
- **اتجاه الادخار**: رسم نقاط شهرية تبين الادخار (الدخل ناقص المصروفات) مقابل أهداف الخطة المالية، مع مؤشر "على الهدف" ورسائل تحفيزية.
- **تصدير CSV**: زر تصدير التقرير السنوي الشخصي (ملف `annual-{year}.csv`) إلى مجلد التخزين.

### المركز المالي للشركات (الصفحة الرئيسية)
- بطاقة المركز المالي أصبحت **فعّالة بالكامل**: صافي الذمم المدينة والداينة، صافي المركز المالي الملون، والمستحقات المتأخرة.
- **تفاصيل المستحقات المتأخرة**: زر "تفاصيل المستحقات المتأخرة" يعرض قائمة الفواتير المتأخرة (مبيعات ومشتريات) مع اسم الجهة والمبلغ وعدد أيام التأخير.
- إصلاح: البطاقة لم تكن تظهر سابقًا لأن حسابها لم يكن مربوطًا بالصفحة الرئيسية.

### المحركات الجديدة (Core)
- `PersonalAnnualReportCalculator`: التقرير السنوي الشهري بالمقارنة.
- `PersonalCategoryReportCalculator`: توزيع المصروفات حسب الفئات بالنسب والترتيب.
- `SavingsTrendCalculator`: اتجاه الادخار الشهري مع نقاط trailing.

### اختبارات الوحدات
- 26 اختبارًا جديدًا للمحركات الثلاثة، ليصبح المجموع **144 اختبارًا كلها تمر بنجاح**.

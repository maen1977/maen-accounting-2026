# Maen Accounting v2.7.0 — Elevated Business Release

**الإصدار: 2.7.0 (versionCode 9)** — رفع مستوى البرنامج عبر دورة حياة مستندات أعمال كاملة، ومصالحة المدفوعات، وتصفية متقدمة لحركات الأفراد، وتقارير شهرية شاملة للأعمال.

## الميزات الجديدة

### دورة حياة مستندات الأعمال (Edit / Void / Delete)
- يمكن الآن **تحرير** الفواتير (بزيادة الإصدار تلقائيًا)، **إلغاء** الفواتير المرحّلة (Void) بعد حذف مدفوعاتها المرتبطة، و**حذف** الفواتير والمسودات والمدفوعات بأمان.
- خدمة `BusinessDocumentLifecycleService` في Core تتحقق من قواعد الانتقال (نسخة/حالة/مدفوعات مرتبطة) قبل أي عملية.
- فواتير: Draft → Posted → Voided، مع حذف صلب للفواتير وحذف ناعم (Soft Delete) للمدفوعات عبر عمود `IsDeleted` في `payments` (ترحيل قاعدة بيانات رقم 6).

### مصالحة الفواتير والمدفوعات
- محرك `InvoiceReconciliationCalculator` يوزّع مدفوعات كل عميل/مورّد على فواتيره المرحّلة زمنيًا، ويعرض لكل فاتورة: المدفوع، المتبقي، وحالة السداد الكامل.
- شريط متغيرات ملوّن لكل فاتورة مع ملخص إجمالي للمدفوعات والمتبقي.

### بحث وتصفية متقدمة
- **شركات**: بحث نصي فوري في الفواتير (رقم/عميل/مبلغ/حالة) والمدفوعات والعملاء.
- **أفراد**: بطاقة فلتر جديدة على لوحة القيادة (التصنيف + نطاق التاريخ + البحث النصي) عبر `PersonalMovementFilterEngine`، مع ملخص المودعات/الإنفاق/الصافي بعد التصفية وزر مسح الفلتر.
- زر تفعيل/تعطيل للعملاء (يُمنع تعطيل عميل له فواتير مرحّلة).

### تقارير الأعمال الشهرية (تبويب جديد)
- صفحة "التقارير" ضمن تبويبات حسابات الشركات تعرض: المبيعات، المشتريات، المحصلات، مدفوعات الموردين، صافي التدفق النقدي، أفضل وأضعف شهر، وجدول شهري تفصيلي بتصدير CSV.

### مبادرات أخرى
- تصدير CSV للتقرير السنوي الشخصي وحركات البحث المتقدم.
- بطاقات ملونة لبطاقات التقرير السنوي (الدخل/الإنفاق/الصافي/الاتجاه).
- أكثر من 40 مفتاح ترجمة ثنائي اللغة جديد (T464–T542).

## تقنيًا
- ترحيل قاعدة بيانات رقم 6: `ALTER TABLE payments ADD COLUMN IsDeleted INTEGER`.
- ~30 اختبار وحدة جديد (الإجمالي 174 اختبارًا، جميعها ناجحة).
- الإصدار: 2.7.0، versionCode 9.

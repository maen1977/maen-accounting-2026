# Maen Accounting v2.8.0 — Security & Quality Release

**الإصدار: 2.8.0 (versionCode 10)** — حماية سلامة البيانات عبر تجزئة التشفير (Integrity Hash) الموصولة بالحفظ والسحابة، ومحركات جودة بيانات وأعمار الديون، وتنظيف المدخلات في كل مسارات الاستيراد والحفظ.

## الميزات الجديدة

### سلامة البيانات (Data Integrity)
- عمود `integrity_hash` جديد في جداول `invoices` و`payments` و`profit_entries` (ترحيل قاعدة بيانات رقم 7) يحسَّب تلقائيًا عند كل حفظ.
- تجزئة SHA-256 تربط هوية السجل ومالكه وإصداره وقيمه المالية: أي تلاعب بالسجل يُكشف فورًا.
- المزامنة السحابية ترفع التجزئة مع كل سجل، وعند التنزيل تُرفض السجلات ذات التجزئة غير المطابقة تلقائيًا (حماية من التلاعب في السحابة أو النقل).

### مدقق جودة البيانات
- لوحة "جودة البيانات" الجديدة على شاشة الأفراد تحذّر من: حركات بلا تصنيف، قيم سالبة شاذة، عملاء غير مستخدمين.
- تقارير الأعمال تعرض عدد الفواتير المسودة غير المرحّلة والعملاء المهملين.

### أعمار الديون (Aging Report)
- جدول أعمار الديون يوزّع الفواتير المستحقة في خمس فئات زمنية (حالي / 1–30 / 31–60 / 61–90 / +90 يومًا)، منفصلًا بين الذمم المدينة والمدينة بها.

### حماية المدخلات
- `InputSanitizer` يُنظف كل النصوص (إزالة الأحرف التحكمية، قص الحدود: اسم 80 / ملاحظات 300 / رقم 40 حرفًا) عند الحفظ والاستيراد.
- ملفات الاستيراد القديمة (النسخ الاحتياطية) تُختم بتجزئة السلامة وتُنظف مدخلاتها نصيًا عند الاستيراد.

### مبادرات أخرى
- محرك التحقق `BusinessDocumentValidator` موصول الآن بمسارات الحفظ الفعلية للفواتير والمدفوعات والعملاء.
- أكثر من 8 مفاتيح ترجمة ثنائية اللغة جديدة (T543–T550).

## تقنيًا
- ترحيل قاعدة بيانات رقم 7: أعمدة `IntegrityHash` في الجداول الثلاثة.
- 21 اختبار وحدة جديد (الإجمالي 195 اختبارًا، جميعها ناجحة).
- الإصدار: 2.8.0، versionCode 10.

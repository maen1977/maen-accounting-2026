# تفعيل تسجيل الدخول الحقيقي مع Firebase

هذه النسخة تعدل شاشة البداية حتى لا يكتفي التطبيق بحفظ الإيميل محليًا.
إذا كان Firebase متاحًا ولا يوجد مستخدم مسجل فعليًا، سيظهر نموذج تسجيل الدخول/إنشاء الحساب قبل فتح البرنامج.

النتيجة:
- إنشاء مستخدم فعلي داخل Firebase Authentication
- إمكانية رفع النسخة إلى Firestore
- إمكانية الاسترجاع على جهاز آخر بعد تسجيل الدخول بنفس الإيميل وكلمة المرور

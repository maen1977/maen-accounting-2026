# تقرير التدقيق والتعديلات الأخيرة

## ما الذي تمت إضافته في هذه النسخة
- تحسين الواجهة العامة لتصبح أوضح وأسهل في الاستخدام اليومي.
- الحفاظ على الحفظ المحلي داخل الجهاز وقاعدة البيانات والنسخة الاحتياطية JSON.
- إضافة قسم متصل بالإنترنت في الواجهة الرئيسية يعرض:
  - سعر الذهب للأونصة
  - سعر الفضة للأونصة
  - سعر اليورو مقابل الدولار
- إضافة تحديث يدوي وتحديث دوري لمؤشرات السوق.

## مصادر مؤشرات السوق
- الذهب والفضة: `api.gold-api.com`
- EUR/USD: `api.frankfurter.dev`

## ما يجب فحصه على جهاز Flutter قبل الإطلاق
1. `flutter pub get`
2. `flutter analyze`
3. `flutter run`
4. `flutter build apk --release`
5. التأكد من صلاحية الإنترنت في AndroidManifest.

# إضافة التاريخ والساعة والطقس حسب موقع الجهاز

تمت إضافة قسم جديد في الواجهة الرئيسية يعرض:

- التاريخ الحالي
- الساعة الحالية
- حالة الطقس الحالية
- درجة الحرارة
- الحرارة المحسوسة
- سرعة الرياح

## كيف يعمل
- يطلب التطبيق إذن الموقع من الجهاز.
- بعد منح الإذن يتم تحديد إحداثيات الجهاز.
- يتم جلب الطقس الحالي حسب الموقع.
- يتم عرض الوقت المحلي والطقس في الواجهة الرئيسية.
- إذا تعذر الاتصال بالإنترنت، يحاول التطبيق عرض آخر بيانات ناجحة محفوظة.

## مهم على Android
إذا تم إنشاء مجلد `android` تلقائيًا عبر `flutter create` أو عبر GitHub Actions، فملف الـ workflow يضيف أذونات:
- ACCESS_COARSE_LOCATION
- ACCESS_FINE_LOCATION
- INTERNET

## بعد التحديث
نفّذ:
```bash
flutter pub get
```

ثم:
```bash
flutter run
```

وإذا كنت تستخدم Firebase:
```bash
flutterfire configure
```


## مهم للأندرويد
تحتاج النسخة المبنية إلى صلاحيات الموقع داخل AndroidManifest.xml حتى يعمل الوقت والطقس حسب موقع الجهاز.
